### 2. Selfie Capture

- Face detection

### 3. Face Matching

- Confidence scoring
- Match result

### 4. Decision Engine
- Rule-based evaluation
- Risk assessment
- Final decision

### 5. Result
- Status update
- User notification
- Audit logging
